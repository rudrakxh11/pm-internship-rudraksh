# 1. Project Overview

The Expense Tracker Application was developed to help users manage personal finances by tracking expenses, categorizing spending, monitoring budgets, and generating reports.

The project was executed using Agile methodology with sprint-based planning, stakeholder reviews, and periodic status reporting.

The objective of the project was to provide a simple and efficient platform for users to gain visibility into their spending habits and improve financial management.

---

# 2. Delivered Features

The following features were successfully delivered:

* User Registration and Login
* User Profile Management
* Add Expenses
* Edit Expenses
* Delete Expenses
* Expense Categorization
* Monthly Expense Dashboard
* Budget Tracking
* Expense Reporting
* Notification System
* Search and Filter Expenses
* Basic Analytics Dashboard

All planned core functionalities were completed and tested successfully.

---

# 3. Undelivered Features and Reasons

The following features were identified during planning but were not implemented:

## AI-Based Expense Prediction

**Reason:**
Feature was considered lower priority and deferred due to project timeline limitations.

## Bank API Integration

**Reason:**
Integration required additional security reviews and external API dependencies which were outside the project scope.

## Mobile Application

**Reason:**
Project scope was limited to web application delivery.

# 6. Key Lessons Learned

* Early stakeholder engagement reduced requirement changes.
* Regular sprint reviews improved project transparency.
* Clear communication channels reduced misunderstandings.
* Maintaining a RAID Log improved risk visibility.
* Weekly status reporting helped track progress effectively.
* Proper sprint planning improved team productivity.
